갯벌친구 설치 방법

앱 장터에서 받는 게 아니라, 인터넷 주소를 휴대폰 홈 화면에 붙여 앱처럼 쓰는 방식이에요. 가입·결제 없이 1분이면 돼요.

안드로이드(갤럭시 등)아이폰

안드로이드

갤럭시·LG 등. 크롬이나 삼성 인터넷으로 하세요.

  1. 갯벌친구 링크를 크롬으로 열어요.
    카톡에서 눌렀다면 오른쪽 위 ⋮ → "다른 브라우저로 열기"를 눌러 크롬으로 열어요.
  2. 화면 아래에 "앱 설치" 또는 "홈 화면에 추가" 안내가 뜨면 바로 눌러요.
    안 뜨면 크롬 오른쪽 위 ⋮를 누르고 "홈 화면에 추가"(또는 "앱 설치")를 눌러요.
  3. [설치](또는 [추가])를 눌러요.
  4. 홈 화면에 생긴 갯벌친구 아이콘으로 열면 앱처럼 써요.

삼성 인터넷이면: 아래 ≡ 메뉴 → "현재 페이지 추가" → "홈 화면".

아이폰

꼭 사파리(Safari)로 하세요. 크롬·카톡 창에서는 홈 화면 추가가 안 될 수 있어요.

  1. 갯벌친구 링크를 사파리로 열어요.
    카톡에서 눌렀다면 오른쪽 아래 나침반 아이콘이나 ⋯ → "Safari로 열기"를 눌러요.
  2. 화면 아래 가운데 공유 버튼(네모에 위 화살표 □↑)을 눌러요.
  3. 메뉴를 조금 내려서 "홈 화면에 추가"를 눌러요.
  4. 이름이 "갯벌친구"인지 보고 오른쪽 위 [추가]를 눌러요.
  5. 홈 화면에 생긴 갯벌친구 아이콘으로 열어요.

처음 쓸 때 알아 두면 좋아요

위치 허용

  • "내 위치 보기"·친구 위치 공유를 쓰려면 위치를 물을 때 허용을 눌러요.
  • 안드로이드에서 실수로 거부했다면: 설정 → 애플리케이션 → 크롬(또는 갯벌친구) → 권한 → 위치 → 앱 사용 중에만 허용.
  • 아이폰에서 실수로 거부했다면: 설정 → 개인정보 보호 및 보안 → 위치 서비스 → Safari 웹 사이트 → "앱을 사용하는 동안".

새 버전 받기

  • 인터넷이 되면 열 때마다 새 버전을 받아요. 예전 화면이 보이면 앱을 완전히 닫았다가 다시 열어요.

친구 위치 공유 링크를 받았을 때

  • 안드로이드: 링크를 크롬으로 열고 [참여]를 누르면, 그 뒤엔 홈 화면 아이콘으로 열어도 이어져요.
  • 아이폰: 링크가 사파리로 열려요. 사파리에서 [참여]를 누르고 그 사파리 창을 켜 둔 채로 써요. 홈 화면 아이콘과는 따로 돌아가요.
  • 공유는 앱 화면을 켜 둔 동안만 돼요. 화면이 꺼지면 잠시 멈춰요.

알림

  • 간조 알림은 앱 화면을 켜 둔 동안 울려요. 현장에서는 화면을 켜 두거나 물때를 직접 확인하세요.
