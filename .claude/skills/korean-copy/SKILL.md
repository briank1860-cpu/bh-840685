# 갯벌친구 문장 쓰기

읽는 사람은 아이·연인과 주말에 갯벌을 찾는 초보자다. 문장은 "옆에서 차분히 알려 주는 믿을 만한 사람"의 말이어야 한다. 아 다르고 어 다르다 — 같은 사실도 고르는 말에 따라 읽는 사람의 기분이 달라진다.

바탕: 국립국어원 공공언어 바로 쓰기의 세 기준 — 정확성(어문 규범·사실), 소통성(쉬운 말·간결), 수용성(상대를 존중하고 차별·비하·권위적 표현을 피함).

## 1. 말투
- '~해요 / ~예요 / ~있어요'로 끝나는 완전한 문장. 한 칸에 두세 문장까지.
- 메모체 금지: '~함, ~됨, ~음, ~임, ~것, ~할 것' (예: "인파 많음" → "사람이 많아요").
- 명령조 대신 권유: "챙길 것" → "챙기세요", "금지" 안내도 "~하면 안 돼요"·"~할 수 없어요".
- 감탄·과장 없이 담담하게. '대박, 미쳤다, 폭주, 초토화' 같은 말은 쓰지 않는다.

## 2. 단어 고르기(불쾌감 주는 말 피하기)
| 쓰지 않음 | 이렇게 |
|---|---|
| 무리, 떼, 몰려듦(사람에게) | 사람들, 방문객 |
| 꾼, ~충, 진상 | 해루질하는 분, 방문객 |
| 외면당함, 털림, 꽝(비꼬는 투) | 거의 못 잡았어요, 잘 안 잡혔어요 |
| 인파 폭주, 아수라장 | 사람이 아주 많아요 |
| 노인네, 애들 | 어르신, 아이 |
| 공침 | 하나도 못 잡았어요 |
| 뻘물 | 흙탕물, 물이 흐려요 |
- 특정 지역·어촌계·주민을 깎아내리는 말 금지("텃세 심함" → "어촌계가 관리하는 곳이라 안내를 따라야 해요").
- 겁주는 말 대신 사실과 할 일: "죽을 수도" → "물이 빨리 차올라 고립될 수 있어요. 간조 1시간 뒤엔 나오세요."

## 2-1. 시제 — 과거 시점은 과거형, 현재 시점은 현재형
- 후기·영상·보도·직접 기록에서 본 '그날 있었던 일'은 과거형: "사람들이 랜턴을 켜고 들어가기 시작했어요(2026-08 후기)", "10kg 넘게 잡았다는 후기가 있어요", "바람이 셌던 밤엔 하나도 잡지 못했어요".
- 사고·통제·개정 같은 지난 사건도 과거형: "2026년 4월 70대 한 분이 숨졌어요", "1년간 출입을 막은 적이 있어요".
- 지금도 그런 사실은 현재형: 시설·요금·주차·규칙·법·지형·운영 시간·잡는 방법("화장실이 있어요", "호미로 파서 잡아요", "소라는 5cm 이하면 잡을 수 없어요").
- 앞으로 일은 미래·예정: "2027년 봄 시행될 예정이에요".
- 한 문장 안에서 시점이 섞이면 문장을 나눈다: "예전엔 밤에 잡던 곳이에요. 지금은 밤에 들어갈 수 없어요."

## 3. 쉬운 말
- 처음 나오는 해루질 용어는 괄호로 풀이: 간조(물이 가장 많이 빠질 때), 사리(물이 많이 빠지는 날), 조금(물이 적게 빠지는 날), 물때.
- 기호·약어 풀기: '7m/s' → '초속 7m', '~' 범위는 그대로 써도 된다(9~11월).
- 외래어·영어는 우리말로: 포인트 → 자리(지도 '포인트'는 예외), 스팟 → 장소.

## 4. 사실 그대로
- 숫자·요금·시간·날짜·지명은 원문 그대로. 없는 사실을 보태거나 빼지 않는다.
- 확실하지 않으면 그 정도를 살린다: "~라는 후기가 있어요", "~라는 자료가 있어요(확인 필요)".
- 출처 표시는 문장 끝 괄호에 날짜와 종류만: (2026-08 후기), (2026-10 보도), (해경 공지). 블로그 아이디·플랫폼 내부 말('요약만', 'Threads 해시태그 수준')은 화면에 쓰지 않는다(collect-log.md에만).
- 후기 원문 말투를 그대로 옮기지 않는다. 뜻만 옮겨 이 기준으로 다시 쓴다.

## 5. 고치기 예
- "간조 약 2시간 전부터 헤드랜턴 무리가 들어감(2026-08 후기)"
  → "밤에는 물이 가장 빠지는 때(간조) 2시간 전부터 사람들이 랜턴을 켜고 들어가기 시작해요(2026-08 후기)."
- "주말·연휴 첫물~사리 때 인파 매우 많음" → "주말·연휴에 물이 많이 빠지는 날(사리 무렵)은 사람이 아주 많아요."
- "2022-11 부부 영상은 '용왕님이 외면' — 늦가을 조과는 약했음." → "늦가을(11월)엔 거의 못 잡았다는 영상이 있어요(2022-11)."
- "근처에 가게 없음, 물·간식 챙기기(wooging_ 2026-06)." → "근처에 가게가 없어요. 물·간식을 챙기세요(2026-06 후기)."

## 6. 쓰고 나서 확인
1. 소리 내어 읽었을 때 사람에게 하는 말처럼 자연스러운가.
2. 아이와 함께 온 부모, 어르신, 그 마을 주민이 읽어도 언짢지 않은가.
3. 숫자·날짜·지명이 원문과 같은가.
4. 메모체·거친 말·아이디가 남지 않았는가: `grep -nE '(함|됨|음|임|것)(\(|$|\.)|무리|공침|뻘물'`
